# 몬스터 믹스 (MVP)

소울을 모아 몬스터를 소환하고, 합성해서 상위 몬스터를 만드는 턴제 RPG 웹게임의 시제품입니다.
목표: 10분 플레이했을 때 "합성 한 번만 더" 하고 싶어지는지 확인.

- 플레이: `index.html` (빌드 없이 브라우저로 열면 됨, 폰 세로 화면 기준)
- 규칙 테스트: `test.html` 또는 `node js/tests.js`
- 밸런스 숫자: `js/balance.js` 한 파일에서 고치고 새로고침

## 파일
| 파일 | 하는 일 |
|---|---|
| `js/balance.js` | 성공률, 스택, 드랍률, 능력치, 적 레벨 등 모든 숫자 |
| `js/data.js` | 속성 5개, 원형 배치(부재료 짝·상성) |
| `js/logic.js` | 합성·소울·드랍·전투 규칙 (화면과 분리) |
| `js/ui.js` | 화면과 입력, 브라우저 저장 |
| `js/tests.js` | 규칙 테스트 + 난이도 자동 전투 시뮬레이션 |
